# 手不由己写下的句子，是灵魂在说话还是意识在接管？

### 笔尖先于解释移动
纸上先出现一个歪斜的字母，写作者说自己没有想过它。几分钟后，句子开始连贯，旁观者把笔尖的速度当作证据，纸张于是成了一个看不见的人的入口。 自动书写最容易被误读的地方，是“我没有刻意想”被迅速翻译成“不是我写的”。意识并非只有开和关两档，习惯动作、暗示和联想可以在不被注意时参与写作。

自动书写在19世纪唯灵论运动中得到广泛传播，常被灵媒用于声称与死者或灵体沟通。 法国心理学家皮埃尔·雅内等人曾研究自动行为与意识分离，相关讨论后来与催眠和解离现象相连。 自动书写要求写作者放松控制，让笔在纸上自行移动。19世纪唯灵论者把它解释成亡灵通信，心理学家和艺术家则把它看成无意识、暗示或创作方法。相同的动作，背后可以有完全不同的世界观。

### “不是我写的”意味着什么
艺术家安德烈·布勒东等超现实主义者把自动书写当作突破理性控制的创作方法。 写作者并不总是完全失去意识，期待、提示、记忆和手部运动都可能影响文本内容。 当一页文字包含作者事先不知道的信息，故事会更像通灵；但信息来源仍需控制实验、记录过程和排除暗示。灵媒会话中的戏剧效果，不能替代可重复的验证。
