# 热点背景墙 ｜ 一条走廊锁住中原与西域：河西走廊为什么是"丝路咽喉"

这两天 B 站有条视频火了——有人开电车挑战穿越河西走廊，从兰州一路往西，过武威、张掖、酒泉、敦煌，最后抵达新疆边缘。看着是场公路旅行，其实他车轮碾过的，是中国历史上最要命的一条通道。两千多年来，谁握住河西走廊，谁就握住了中原与西域之间的咽喉；丝绸之路能通能断，几乎全系于这条夹在祁连山与沙漠之间的狭长地带。

**一条被大山和沙漠挤出来的走廊**

河西走廊的"走廊"二字，是地理硬挤出来的。它南靠祁连山，北邻沙漠与剥蚀山地，是一条东西延展的狭长平地。史料里说得很清楚：东段有石羊河水系、武威盆地，中段黑河滋养出"金张掖"的绿洲，西段疏勒河与党河养出敦煌绿洲，外围则是大片戈壁沙丘。年降水量从东到西骤减，武威一百五十八毫米，敦煌只有三十六点八毫米，干燥度西段高达八到二十四。换句话说，这是一条靠雪水活下来的生命线——没有祁连山的冰川融水，就没有绿洲，也就没有走廊。

正是这种"两山夹一水"的格局，让它成了唯一能走大军的通道：南边是青藏高原，北边是蒙古高原与沙漠，只有这条有水草的窄带，能让商队、军队、使节年年往复。

**张骞"凿空"，十三年换来一条路**

河西走廊真正进入中原视野，是因为匈奴。汉武帝想联络大月氏夹击匈奴，建元二年（前 139 年）派张骞出使。张骞一出陇西，就在走廊东端被匈奴俘获，扣了十多年，逃出后西行大宛、康居，才抵达大月氏。大月氏不肯应约，他东归时又在若羌被截，元朔三年（前 126 年）才回长安——前后十三年。元鼎四年（前 119 年）他又二次出使乌孙，副使分赴大宛、康居、大夏、安息诸国。

张骞这趟"凿空"之旅，把大宛、康居、安息、身毒等国的方位、物产、距离第一次系统带回中原。史书称从此"汉与西域的交通建立起来了"。但张骞能走通，前提是走廊先得回到汉手心里。

**霍去病打下来的"河西四郡"**

元狩年间，年轻将领霍去病两度出击河西。一次过焉支山千余里，歼敌八千；一次出陇西、北地二千余里，过居延、攻祁连山，俘三万余人。匈奴昆邪王杀休屠王率四万人降汉。武帝遂"在河西设置酒泉、武威、张掖、敦煌四郡"——这就是著名的河西四郡，走廊就此平定。前 111 年敦煌置郡，"为河西四郡之一"；张掖因城西甘浚山泉味甘得名，有"金张掖、银武威"之誉；武威是走廊东端门户；酒泉居中。四郡一立，中原势力正式楔入西域门户。

汉武帝还"筑河西长城，起亭障直至盐泽（今罗布泊）"，设使者校尉、西域都护府，移民屯田。从此汉使与商人"相望于道"，中亚西亚商胡"日欸于塞下"。丝路南北两道都从敦煌分出：南路经鄯善、于阗越葱岭，北路经车师、龟兹、疏勒越葱岭，终点都指向大秦（罗马）。中国丝绸由此西去，西方物产由此东来。

**佛教东传的第一站，落在凉州与敦煌**

走廊不只是商道，还是文明通道，尤其佛教。史料说"凉州（治姑臧，今武威）是天竺、西域至中原必经之地，佛教从丝绸之路传入中原，首先就经凉州"，所以"凉州之佛教早于内地"。西晋译经最多的竺法护就在敦煌译经；北凉时期，昙无谶到凉州，佛教大盛。

敦煌更因"地接西域"，村坞相属、多有塔寺。城东南三危山下的莫高窟（千佛洞），始凿于前秦，经西晋、北周、隋、唐、五代、宋、西夏、元增建，延续近千年，现存洞窟数百、塑像数千身、壁画五万多平方米。与它并称的还有西千佛洞、榆林窟（万佛峡）。佛教石窟本源于印度，经犍陀罗艺术（希腊与印度风格混合）传入，在河西与中国传统结合，"显示着佛教中国化的倾向"——云冈、龙门都由此脉络而来。可以说，河西走廊是佛教中国化的最初实验室。

**走廊上的政权更迭**

这条通道太肥，谁都想要。十六国时，前凉、后凉、西凉、北凉先后在武威、张掖、酒泉一带建都；西凉李暠"敦劝稼穑"，一度强盛。唐代瓜、沙、肃、甘各州俱为要地。北宋时，党项李元昊占瓜州、沙州、肃州，把河西全纳入西夏（1038 年建国），宋夏反复拉锯，1044 年和议后"重开边境市场，恢复民间贸易"。一条走廊，串起了汉、匈、鲜卑、党项诸族的进退。

**回到那趟电车**

所以那条"电车穿越河西走廊"的视频，表面是风景，底下是 layers 的历史：祁连山的雪水、张骞十三年的囚徒路、霍去病十八岁封侯的河西之战、四郡的烽燧、莫高窟的千年颜料、以及往来不绝的商胡与译经僧。今天的 G30 连霍高速大致重叠在古丝路上，车轮下的，依然是那条锁住中原与西域的咽喉。两千年来，它从未真正安静过。
