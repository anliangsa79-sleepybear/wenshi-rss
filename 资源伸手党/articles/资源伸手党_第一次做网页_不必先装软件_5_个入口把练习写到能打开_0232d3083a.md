# 第一次做网页，不必先装软件：5 个入口把练习写到能打开

第一次学网页，最容易发生的事是收藏了一堆教程，却迟迟没有看到自己的页面。更有效的路线是先写出一小段 HTML，再补课程、练习和项目。下面 5 个入口不是并列工具，而是一条从“看懂标签”到“有人帮你挑错”的路线。

**1. W3Schools**（https://www.w3schools.com/html/）

先用 W3Schools 看 HTML 教程。打开后选一个最小例子，先改标题或文字，再运行页面，看浏览器到底变了什么。它的优势是示例短、反馈快，适合第一次接触标签的人；与 freeCodeCamp 相比，它更像随手查的参考书，不会强迫你一次学完整套课程。

![W3Schools HTML 教程](资源伸手党·成稿·05·第一次做网页·20261024-1030.png)

**2. freeCodeCamp**（https://www.freecodecamp.org/learn/）

页面能改动之后，进入 freeCodeCamp 的互动课程。第一步是选一个入门模块，按题目要求修改代码，完成后看测试是否通过。它把知识点切成连续任务，适合需要明确进度的人；部分学习记录可能需要账号保存，但基础课程本身可以直接浏览和练习。

![freeCodeCamp 学习页面](资源伸手党·成稿·05·第一次做网页·20261024-1030_02_freeCodeCamp.png)

**3. The Odin Project**（https://www.theodinproject.com/paths）

想知道“下一步该学什么”，就看 The Odin Project 的 Paths。它不是一个点开就能完成的小练习，而是把工具、基础和项目排成路线。打开后先看路径目录，挑出当前能完成的一小段，不要一口气把全栈路线收藏完。它比前两个站更重项目和本地实践，适合愿意持续投入的人。

![The Odin Project 学习路线](资源伸手党·成稿·05·第一次做网页·20261024-1030_03_Odin.png)

**4. CodePen**（https://codepen.io/pen/）

等你想把一个小想法立刻放到页面里，CodePen 是很好的试验台。打开新 Pen 后，分别在 HTML、CSS、JS 区域写一点内容，预览会随着修改变化。它的价值不是替代系统课程，而是让你看到代码和画面之间的距离；适合做按钮、卡片和小动画这类短实验。公开保存作品前，要注意代码和素材的授权。

![CodePen 新建 Pen 页面](资源伸手党·成稿·05·第一次做网页·20261024-1030_04_CodePen.png)

**5. Exercism**（https://exercism.org/tracks）

最后用 Exercism 练一门具体语言的基础。打开 tracks 页面先选语言，再看练习目录和安装要求；它更强调一道题一道题地写，部分语言还可以获得导师反馈。它和 CodePen 的区别是没有即时视觉效果，却更适合练逻辑、命名和函数。不同语言的运行方式、账号和练习规则可能不同，先看当前轨道说明。

![Exercism 语言练习路线](资源伸手党·成稿·05·第一次做网页·20261024-1030_05_Exercism.png)

最小可行路线是：W3Schools 改一个标题，freeCodeCamp 过一关，CodePen 做一个小按钮。只要今天能打开一个自己改过的页面，学习就已经从收藏夹里出来了。
