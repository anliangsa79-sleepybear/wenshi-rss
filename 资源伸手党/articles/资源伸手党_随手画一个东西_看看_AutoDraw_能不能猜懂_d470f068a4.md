# 随手画一个东西，看看 AutoDraw 能不能猜懂

开会时想画一个小图标，手边没有设计师，也不想为一个箭头、杯子或小房子打开复杂软件，可以先试试 Google 的 AutoDraw。它的有趣之处不是把你变成画家，而是你只要画出一个大概，系统就会把“可能是什么”列出来。

打开后先点 Start Drawing，进入画布。左侧工具栏里选择带星号的 AutoDraw 工具，在白色画布上随手画几笔，不用追求轮廓准确；画到一半时，顶部会出现一排候选图标，点一个就会用更规整的线稿替换你的草图。你可以继续加颜色、文字或形状，再从菜单里的 Download 导出结果。

![AutoDraw 实际画布与工具栏](资源伸手党·小功能·01·AutoDraw猜图·20261030-1030.png)

它适合做草稿、课堂小游戏和临时的示意图，不适合把候选图标当成独家原创素材。候选结果取决于你画的速度和形状，有时系统猜得很准，有时会给出完全不相关的答案；这正是它好玩的地方。网页可以直接打开，不需要先装软件，下载前也要看看图标的来源和使用边界。

如果候选栏没有你想要的图标，不必反复重画同一个细节，可以换成更概括的轮廓。AutoDraw 识别的是整体形状和常见画法，先画“一个杯子的外轮廓”通常比努力画出杯柄上的纹理更容易得到有效建议。

如果你只是要一个简单的杯子或箭头，今天就打开 AutoDraw，先画一个歪得不能再歪的轮廓，再看看它给出的第一排猜测。你会很快知道，这个工具适合“把意思画出来”，而不是替你完成一张完整海报。

画完后再试一次同一对象，换一种更夸张的画法，结果通常会很不一样。
