# 临时要做一套有出处的网页或提案素材？这 5 个免费入口按顺序接起来

![ 临时要做一套有出处的网页或提案素材？这 5 个免费入口按顺序接起来 ](资源伸手党·成稿·01·网页提案素材·20261022-1030.png)

临时接到一个小项目，最容易卡住的不是没有想法，而是打开空白画布后，发现图标、字体、示意图和版式都没有着落。与其在搜索引擎里来回捡素材，不如先把这条小路线存下来：先搭结构，再补图形，最后处理字体和授权。下面这些站点我按真正做一页东西的顺序排好了。

**1. OfficePLUS**  https://www.officeplus.cn/
先从微软的模板库看一眼。打开后按汇报、计划、海报等关键词筛选，不要急着下载，先看一套模板的页序能不能替你解决开头、中段、结尾三个问题。它和后面几个站点的区别，是先给你一副骨架，适合时间只剩半天、但又不想从白页开始的人。模板里的图片、字体和图标仍要逐项看使用说明，免费不等于每个素材都能脱离模板随便转卖。

**2. Figma**  https://www.figma.com/
把刚才的页序搬进 Figma，先用一张空白 Frame 定下比例，再把标题、卡片和按钮排出来。它更像共同工作的桌面：需要同事批注，或者要把网页想法先做成能点击的样子，就在这里完成。免费档适合小型个人项目和原型，团队权限、历史版本和部分高级能力会受计划限制。

**3. unDraw**  https://undraw.co/
页面有了结构，再到 unDraw 找一张不抢标题的插画。打开后先用颜色选择器调成接近项目主色，再下载 SVG 或 PNG。它的好处是图形风格统一、能改色，不必从一堆摄影图里找看起来差不多的配图。站点许可允许较自由地使用，但如果项目有特殊品牌要求，仍应保留页面上的许可说明。

**4. SVG Repo**  https://www.svgrepo.com/
需要一个电话、文件夹、箭头或地球图标时，来这里按英文关键词搜，再点开单个图标的许可页。不要只看搜索结果卡片；同一个站里不同作者的授权可能不同。它比 unDraw 更适合补零件，适合要画流程图、产品界面或提案信息图的人。

**5. Google Fonts**  https://fonts.google.com/
最后再定字体。先输入项目需要的字母或风格，选一款标题字体和一款正文无衬线字体，别把整套页面装成字体展览。Google Fonts 的开源许可通常很友好，但下载或嵌入前要看具体字体的许可文件，尤其是要做商业交付时。

这条顺序的关键，是不让素材反过来支配内容：OfficePLUS 解决结构，Figma 解决关系，unDraw 和 SVG Repo 补视觉，Google Fonts 收尾。下次再遇到今晚要交一页的任务，先打开前两个站，空白画布会小很多。
