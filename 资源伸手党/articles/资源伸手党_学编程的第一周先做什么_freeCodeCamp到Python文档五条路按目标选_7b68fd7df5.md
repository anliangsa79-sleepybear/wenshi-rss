# 学编程的第一周先做什么？freeCodeCamp到Python文档五条路按目标选

零基础学编程最容易同时打开五个课程，几天后却没有一个作品能运行。先选一个目标：做网页、练一种语言、理解学习顺序，或学会查官方资料。下面五个入口不必全部完成，选一条坚持两周，比收藏一整套课程更实际。

![](images/资源伸手党·成稿·17·零基础学编程·20261009-0903.png)

## 💻 按目标选择第一站

[freeCodeCamp](https://www.freecodecamp.org)把讲解和练习放在一起，适合边做边学网页基础。每完成一小节，试着改一段代码，确认自己能解释结果。

[The Odin Project](https://www.theodinproject.com)按项目组织学习内容，适合希望从网页基础逐步做出作品的人。先看课程要求和项目清单，准备好投入时间再开始。

[Exercism](https://exercism.org)提供多语言练习，适合已经会一点语法、希望通过短题熟悉写法的人。做题后读社区讨论，比较不同实现思路。

[roadmap.sh](https://roadmap.sh)把前端、后端和数据等方向画成路线图。把图当作导航，不要把所有节点都列成“学完才能开始”的门槛。

[Python官方文档](https://docs.python.org/3/)适合查语法和标准库。遇到问题先搜索章节标题、看小例子，再用自己的代码验证；文档不是从头刷完的入门课。

## 🛠️ 用一个小项目把路线落地

做一个网页计时器、文件整理脚本或个人词汇表，功能越小越容易完成。每周只学当前项目需要的部分，记录遇到的报错和解决办法。课程旁听、作业反馈和证书可能条件不同，报名或注册前看清页面说明。

给自己设一个两周检查点：能否独立完成一个很小的功能，能否读懂报错并说明修改了什么。若课程一直停留在复制示例，就先暂停加新课，把现有代码改成自己的主题。遇到技术问题时记录报错、尝试过的步骤和结果，再去查论坛或文档，别人更容易给出有效帮助。学编程不必从“最完整路线”开始，先完成一个能运行、能展示的作品，才知道下一步应该补什么。

项目可以从一个实际困扰开始：把常用链接整理成网页、给文件按日期分类，或做一个能记录习惯的简单表格。写下输入、输出和最小功能，做完后让朋友试用，记录他卡在哪一步。这样你会发现自己缺的是布局、条件判断还是数据存储，然后回到对应课程补一小段。不要频繁换语言；先把一条路线走到第一个可运行成果，再判断是否需要转向。
