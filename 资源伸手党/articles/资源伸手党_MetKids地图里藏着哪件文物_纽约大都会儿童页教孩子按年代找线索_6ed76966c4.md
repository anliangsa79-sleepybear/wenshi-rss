# MetKids地图里藏着哪件文物？纽约大都会儿童页教孩子按年代找线索

在博物馆看见一件器物，孩子问“它从哪里来”，不必先背年代。MetKids把大都会博物馆的儿童内容拆成地图、时间和视频等入口，适合让孩子自己挑一条路线。打开[MetKids](https://www.metmuseum.org/art/online-features/metkids/)，先看页面当前能使用的栏目；这个地址可能进入博物馆保留的旧页面，实际导航以页面显示为准。

## 🗺️ 先从地点找到对象

如果页面提供 Map 入口，让孩子先在地图上选一个区域或对象，再读它的名称和说明。可以问“它为什么会出现在这里”“这个地点离我们有多远”，让孩子先描述自己看见的内容，再一起找页面里的线索。地图帮助建立地点关系，但不一定解释器物的全部历史；遇到没有写明的信息，先留作问题。

## ⏳ 再把时间拨回去

Time Machine 一类入口适合比较不同年代的生活用品、服饰或建筑。让孩子挑两个时期，找一处看得见的变化：材料、形状、用途或使用者。若不想读长文字，可以先看短视频，再回到对象页核对名称和背景。目标不是记住所有艺术史，而是学会从一件东西往外追问。

页面以英文内容为主，亲子共读会更顺；栏目状态和链接可能调整。馆藏图片可以浏览，不代表每张都能下载或商用，使用时要看具体对象页。今天只选一件藏品，记下它的地点、年代和一个仍未解答的问题。一次自己找到对象的经历，比成人讲完一整段馆史更容易留下印象。

可以让孩子挑两件不同时期的对象，观察材料或形状有什么变化，再回到对象说明确认年代和地点。遇到页面没有解释的细节，就先写成问题，不用靠想象补故事。MetKids适合陪孩子逛一个主题，不必把地图和时间入口全部点完；如果旧页面里的链接失效，回到大都会博物馆当前的藏品页找同一对象，核对名称和图像权利。

把对象名和馆藏链接一起保存，后续写作还可回到原始目录复核。
