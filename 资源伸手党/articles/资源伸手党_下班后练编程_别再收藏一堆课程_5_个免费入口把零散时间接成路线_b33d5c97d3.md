# 下班后练编程，别再收藏一堆课程：5 个免费入口把零散时间接成路线

![ 下班后练编程，别再收藏一堆课程：5 个免费入口把零散时间接成路线 ](资源伸手党·成稿·02·编程练习路线·20261022-1030.png)

晚上九点打开教程，十点半还停在环境配置完成，这是很多人的编程学习现场。真正能坚持下来的路线，通常不是资源最多，而是每次打开都知道下一步做什么。下面这 5 个入口，按先选方向、再练题、遇到问题回到文档的顺序使用，比把几十个课程收藏夹堆在一起更容易开始。

**1. roadmap.sh**  https://roadmap.sh/
先打开路线图，选择前端、后端、Python 或 DevOps 等方向。第一步不是把所有节点都点亮，而是找出今天能完成的一个小节点，比如 HTML 基础或 Git 的一次提交。它提供的是地图，不是从头讲到尾的课程，适合已经知道自己想往哪走、但总在先学什么上犹豫的人。

**2. MDN Web Docs**  https://developer.mozilla.org/
如果选的是网页方向，第二站放在 MDN。打开后从 HTML、CSS 或 JavaScript 的学习区进入，再用页面里的示例验证一个概念。MDN 的价值不在于把每件事讲得最轻松，而在于它会把浏览器实际支持什么、一个属性有哪些边界写清楚。把它当作查原文的地方，不要期待一晚上读完。

**3. Exercism**  https://exercism.org/
学完一个小概念，就去 Exercism 做一题。先选语言，再从最短的练习开始；提交后可以比较其他写法，部分语言还有导师反馈。它与教程的区别是必须动手，答案不再停留在我看懂了。免费练习很多，但不同语言的导师活跃度会变化，遇到等待时先看社区解法，不要把反馈当成唯一出口。

**4. Codewars**  https://www.codewars.com/
想把练习变成一点游戏感，可以换到 Codewars。先从低难度 kata 开始，提交后才能看到别人的解法；这个顺序很适合发现自己写得太绕的地方。它更像短跑题库，不替你安排完整课程，适合已经会一点语法、想每天做一道题保持手感的人。

**5. Python.org**  https://www.python.org/
如果学 Python，遇到这个函数到底怎么定义的问题，回到官方文档，而不是继续翻二手截图。打开 Documentation 或 Tutorial，先确认版本，再复制最小示例到自己的环境里。官方文档不负责哄你学下去，却能帮你把传言和真实行为分开。

把路线图当路牌，把 MDN 和 Python 文档当地图，把 Exercism 与 Codewars 当练习场，每晚只完成一个小动作就够了。今天可以先打开 roadmap.sh，选一个最小节点；学习不是把网页全部看完，而是让明天的自己接得上今天的代码。
