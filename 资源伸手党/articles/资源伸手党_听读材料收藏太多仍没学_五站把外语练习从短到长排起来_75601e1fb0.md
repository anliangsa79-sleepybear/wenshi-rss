# 听读材料收藏太多仍没学？五站把外语练习从短到长排起来

学语言时最容易积累的是收藏夹，而不是每天真的打开的材料。可以按投入从轻到重排一条路：先读一页短文本，再做几分钟听力，最后尝试完整章节。Project Gutenberg 和 Standard Ebooks 提供书籍入口，BBC Learning English 与 ELLLO适合短听力，LibriVox可以把练习延长到有声书。

## 📖 先读一页，再决定读多长

在 [Project Gutenberg](https://www.gutenberg.org/) 按语言或主题找一篇作品，先打开在线文本读一页，不要一开始就下载大部头。它的资源丰富，适合建立阅读耐力，但排版和版本需要自己判断。若更在意电子书格式和目录体验，可试 [Standard Ebooks](https://standardebooks.org/)，它对公版书做了整理；两站的作品版权状态会因地区而异，转载前查看具体页面。

## 🎧 把文字接到短音频上

到 [BBC Learning English](https://www.bbc.co.uk/learningenglish) 选一个短栏目，先盲听，再看页面提供的词汇或文本。之后用 [ELLLO](https://elllo.org/) 找不同说话者和主题的材料，听大意后再核对文字。BBC课程感更强，ELLLO的说话者与口音更丰富；选一段几分钟能听完的内容，比一次打开整套课程容易坚持。

![BBC Learning English 页面](images/资源伸手党·成稿·04·免费听读材料排好·20261024-1030_03_BBCLearning.png)

![ELLLO 听力材料页面](images/资源伸手党·成稿·04·免费听读材料排好·20261024-1030_04_ELLLO.png)

当你能跟住短材料，再去 [LibriVox](https://librivox.org/) 挑一章公版有声书。志愿朗读者的语速和音质可能不同，可以先试听再决定。

![LibriVox 有声书页面](images/资源伸手党·成稿·04·免费听读材料排好·20261024-1030_05_LibriVox.png)

今天只做“听一段短音频，再读一页文本”。保存书名、听力主题和不懂的词，明天从同一处继续。公版与音频许可要分别看具体条目，不因平台免费浏览就默认能商用。

挑材料时用一个简单尺度：能独立理解大意的部分应该占多数，偶尔查词即可；如果每行都要停下来翻译，就换短一点或更熟悉的主题。听力则先听大意，再看文字找出漏听处，最后回放一次。把阅读与听力安排在同一主题上，能减少切换成本，但不要强求书籍和音频必须来自同一版本。今天的练习结束时写下明天要打开的具体页面和段落。
