# 今晚抬头看什么？Stellarium Web 先把天空变成一张可搜索的星图

夜里站到阳台上，最容易出现的不是“看见一颗星”，而是看见一大片星，却不知道它们叫什么。[Stellarium Web](https://stellarium-web.org/) 把浏览器变成一张互动星图。打开后先同意页面提示，再等待星图加载；顶部搜索框可以输入天体名称，底部工具栏则提供星座、地平线、显示模式和全屏等控制。

它的第一个玩法是搜索：输入一个熟悉的星体或星座，页面会把目标带到视野里，然后用鼠标拖动天空、滚轮缩放。第二个玩法是换时间或视角，观察同一片天空怎样移动；这比直接背星座图更容易理解“今晚”和“下个月”为什么不一样。第三个玩法是打开星座线或名称显示，把刚刚找到的目标和周围的星星一起认一遍。它不是一张静态壁纸，而是可以按地点和时间变化的天文工具。

![Stellarium Web 星图界面与搜索入口](资源伸手党·小功能·03·StellariumWeb星图·20261028-1030.png)

浏览器是否能正常加载 WebGL、定位是否被允许、页面是否要求先接受 cookie，都可能影响体验；截图中如果星图还在加载，也能看见搜索栏、工具栏和时间入口。它适合孩子第一次认识星座、观星前做准备，也适合写作者为场景找一个真实的夜空参照。它不能替代专业观测软件的精确设置，更不能保证城市灯光下肉眼一定看得见搜索到的天体。

最省力的用法是先在室内搜索一个目标，再把手机带到窗边或户外对照。页面中的星图、数据和软件界面受网站许可约束，个人学习和展示可以先按页面说明使用；如果要批量截图、制作课程或商业内容，需另查授权。
