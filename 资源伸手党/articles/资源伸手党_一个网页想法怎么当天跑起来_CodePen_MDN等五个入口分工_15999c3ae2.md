# 一个网页想法怎么当天跑起来？CodePen、MDN等五个入口分工

想验证一个按钮或页面布局，不必先安装一堆开发软件。可以先写几行代码看画面，再查规则、搭项目或向别人展示：CodePen适合快速试效果，Replit延伸到多文件项目，MDN和DevDocs用来查文档，Figma帮助讨论页面结构。按问题选入口，比把五个网站都收藏起来更实用。

## 💻 先让一个小组件出现

在[CodePen](https://codepen.io/)打开新编辑区，把 HTML、CSS 和 JavaScript 分别放进对应区域，先做一个按钮或卡片，边改边看预览。它适合短实验，不适合直接存放重要生产代码。

![做网页原型时别先装一堆软件：5个免费入口把想法跑起来](images/资源伸手党·成稿·05·网页原型·20261023-1030.png)

若原型需要多文件、运行环境或后端，再看[Replit](https://replit.com/)的当前工作区。免费层、协作和运行资源可能受账户方案限制，先确认页面提供什么，再决定是否把项目迁进去。

![Replit](images/资源伸手党·成稿·05·网页原型·20261023-1030_02_Replit.png)

## 📖 查清规则，再把页面讲给别人

属性或浏览器行为不确定时，去[MDN Web Docs](https://developer.mozilla.org/en-US/)查示例、参数和兼容性。它是技术参考，不会替你排好每一步课程。

![MDN Web Docs](images/资源伸手党·成稿·05·网页原型·20261023-1030_03_MDN.png)

如果已经知道要找哪个方法或属性，[DevDocs](https://devdocs.io/)的文档目录和搜索可以减少切换；版本有差异时回到项目官方文档。

![DevDocs](images/资源伸手党·成稿·05·网页原型·20261023-1030_04_DevDocs.png)

页面结构需要讨论时，用[Figma](https://www.figma.com/)先画区域和点击路径，不要先把颜色和图标全部做满。它帮助表达结构，不会自动解决代码实现。

![Figma](images/资源伸手党·成稿·05·网页原型·20261023-1030_05_Figma.png)

今天只做一件事：把一个能说明想法的按钮做出来，保存代码和页面状态，再请同伴试用。公开分享前检查素材许可和账户权限；原型完成不等于可以直接上线。

一个小原型可以按三问验收：用户看不看得出按钮用途，点击后有没有明确反馈，返回或刷新会不会丢掉重要状态。先请一个没看过代码的人试用，再根据他停顿的位置改页面。CodePen或Replit适合实验，MDN与DevDocs用于核对技术细节，Figma帮助讨论交互；公开原型前检查隐私、依赖和素材许可。
