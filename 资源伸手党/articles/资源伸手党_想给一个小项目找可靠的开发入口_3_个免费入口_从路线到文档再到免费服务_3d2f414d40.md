# 想给一个小项目找可靠的开发入口：3 个免费入口，从路线到文档再到免费服务

做一个小网站时，最先耗掉时间的通常不是写代码，而是在“学什么、去哪查、服务怎么选”之间来回跳。把这三个问题拆开，先找路线，再查免费服务，最后用一套项目式课程把想法变成能运行的东西，会比收藏几十篇零散教程更容易开始。

第一站可以看 [roadmap.sh](https://roadmap.sh/)。打开后先按角色或技术方向选择一张 roadmap，例如前端、后端、DevOps 或 Python，再把路线上的节点当作待办清单。它的价值不在于替你上课，而是告诉你哪些概念应该先出现、哪些内容可以后补。适合已经有一个模糊方向、但不知道下一周该学什么的人；它提供的是地图，不是每个节点的完整教材。

![roadmap.sh 开发路线入口](资源伸手党·成稿·05·小项目找开发入口·20261028-1030.png)

需要选部署、数据库、监控或测试服务时，可以打开 GitHub 上的 [free-for-dev](https://github.com/ripienaar/free-for-dev)。先用页面搜索或目录找到对应分类，再点进服务的官方链接，核对免费额度、是否需要信用卡、项目是否会休眠以及个人或商业使用限制。它和普通“免费工具推荐”文章的区别是内容以清单和链接为主，适合快速建立候选池，但不应该把清单上的描述当成永久承诺，最终规则要回到服务商页面确认。

![free-for-dev 免费服务清单](资源伸手党·成稿·05·小项目找开发入口·20261028-1030_02_FreeForDev.png)

如果你想边学边做一个能展示的项目，进入 [The Odin Project](https://www.theodinproject.com/)。从 Foundations 或具体技术路径开始，按章节完成练习和项目，再把结果放到自己的仓库里。它比 roadmap.sh 更像一条带作业的训练路线，适合愿意持续写代码、愿意自己排错的人；学习时间更长，也不适合只想临时查一个语法问题的读者。

![The Odin Project 学习路线入口](资源伸手党·成稿·05·小项目找开发入口·20261028-1030_03_Odin.png)

三站的用法可以固定成一个晚上：先在 roadmap.sh 选下一步，再用 free-for-dev 找服务候选，最后在 Odin 里完成一个小项目。所有免费服务都有额度、地区、登录、隐私或商业使用边界，部署前一定打开官方条款；这份清单的作用是缩短寻找时间，不是替你做最终承诺。
