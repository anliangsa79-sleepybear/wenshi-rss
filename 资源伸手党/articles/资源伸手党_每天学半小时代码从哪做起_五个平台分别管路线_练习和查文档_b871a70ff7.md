# 每天学半小时代码从哪做起？五个平台分别管路线、练习和查文档

晚上打开教程却一直停在环境配置，常常是因为每个学习入口都没有明确的下一步。可以把路线图、参考文档和练习题分开：roadmap.sh帮你选方向，MDN和Python.org查规则，Exercism与Codewars让手指真正敲代码。每天只完成一个小节点，比把课程收藏满更接近进步。

## 🧭 先决定今天练哪一步

在[roadmap.sh](https://roadmap.sh/)选择前端、后端、Python或其他路径，先挑一个小节点，不要试图一次点亮整张路线图。网页方向可以去[MDN Web Docs](https://developer.mozilla.org/)看HTML、CSS或JavaScript的教程和示例；它适合核对浏览器行为，不是要你一晚上读完的课程。

## ⌨️ 练习和查文档轮着来

在[Exercism](https://exercism.org/)选一门语言，从短练习开始，提交后比较其他写法。它强调动手，有些轨道提供导师反馈，但活跃程度可能不同。



想增加游戏感时到[Codewars](https://www.codewars.com/)做低难度 kata，完成后再看别人的解法，注意是否有更清楚的写法。它是短题库，不替代系统课程，适合有一些基础后保持手感。



如果学Python，遇到函数或语法行为不确定时回到[Python.org文档](https://www.python.org/)的教程，先确认版本，再运行最小示例。官方文档不负责安排学习节奏，却能帮你核实真实规则。



每天结束时记下改过的代码和明天要做的一步。不同网站的账户、练习和导师安排会变；不要因为某一题卡住就切换五个课程。选一个节点，运行一段代码，再写一句它为何有效，半小时就有了可以接上的成果。

可以用一张简单记录表串起每晚的半小时：今天的路线节点、写过的代码、遇到的问题、下一次要验证的想法。遇到问题先做一个最小示例，再去文档搜索相关术语；不要一次把整段错误信息复制进多个问答网站。这样你能分清自己是概念没懂、环境没配好，还是只差一个符号，也更容易第二天接着练。
