# 家里有本旧书想找电子版，5个免费网站从书名、版本到合法阅读一次查清

家里翻出一本旧书，封面还在，版权页却没了；或者只记得作者和一句情节，想找电子版时，搜索结果总是把你带到不明下载站。找书最好分三步：先确认它是哪一本，再看有没有公开阅读，最后分清“能在线读”和“能自由再利用”不是一回事。

**1. Open Library**  
https://openlibrary.org/

先把记得的书名、作者或 ISBN 输入 Open Library。它最适合做版本侦查：同一本书会列出不同出版社、年份和封面，能帮你确认手里那本到底是哪一版。部分电子书可以在线借阅，但借阅状态、地区和登录要求会变化；如果只是找书目和版本，它已经比直接搜下载链接可靠得多。

![Open Library 首页](资源伸手党·成稿·02·旧书电子版·20261112-1532_03_OpenLibrary.png)

**2. Project Gutenberg**  
https://www.gutenberg.org/

确认书名后，再到 Project Gutenberg 搜一次。它主要收录美国版权已经到期的公版电子书，打开条目通常能直接选择 HTML、纯文本或电子书格式。这里的“免费”首先指阅读和下载不收费，并不等于每个国家都适用同一版权判断；如果准备转载、改编或商用，仍要看作品和所在地区的规则。

![Project Gutenberg 首页](资源伸手党·成稿·02·旧书电子版·20261112-1532.png)

**3. Standard Ebooks**  
https://standardebooks.org/ebooks

如果你已经确认这本书属于公版，Standard Ebooks 值得再查一遍。它把公版英文书重新校订、排版，并提供适合不同设备的电子书格式。打开目录后先按作者或主题筛选，再看条目里有哪些下载格式。它和 Project Gutenberg 的区别，是更强调阅读体验和版式；但它主要是英文书，不能替代中文旧书库。

![Standard Ebooks 目录页](资源伸手党·成稿·02·旧书电子版·20261112-1532_02_StandardEbooks.png)

**4. LibriVox**  
https://librivox.org/

有些旧书找不到合适的电子文本，却能找到免费的朗读版本。LibriVox 收录志愿者朗读的公版书，打开目录后可以按作者、标题和语言找作品，先试听章节，再决定要不要保存。它不是电子书下载站，适合通勤、做家务时听，也能帮你确认书名、章节和版本；版权判断仍要按作品所在地的规则来做。

![LibriVox 公版有声书页面](资源伸手党·成稿·02·旧书电子版·20261112-1532_04_LibriVox.png)

**5. Wikisource**  
https://wikisource.org/

如果旧书属于经典文本，Wikisource 适合做最后一轮全文检索。它由志愿者整理多种语言的公版文本，输入作者或书名后，先看版本页和来源，再进入正文。它的优势是可以顺着章节和原文继续查，缺点是不同语言项目的整理程度不一样，不要把每一页都当成经过同一套校勘的版本。

![Wikisource 文本库页面](资源伸手党·成稿·02·旧书电子版·20261112-1532_05_Wikisource.png)

找旧书不要从“哪里能下载”开始，而要从“我手上这一本到底是哪一版”开始。版本确认了，能不能读、能不能借、能不能再使用，后面自然会清楚很多。
