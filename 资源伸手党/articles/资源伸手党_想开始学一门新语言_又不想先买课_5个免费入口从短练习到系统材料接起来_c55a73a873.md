# 想开始学一门新语言，又不想先买课？5个免费入口从短练习到系统材料接起来

很多人不是没有兴趣，而是第一天就被“教材、课程、词表、计划”吓退了。更轻的办法是先用几分钟练习建立手感，再找一段能听懂的材料，最后用公版文字和有声书把学习拉长。下面的入口不要求一次全用，选两三个就能开工。

![Duolingo 页面](资源伸手党·成稿·05·新语言入门·20261117-1530.png)

**1. Duolingo**  
网址：https://www.duolingo.com/

先用 Duolingo 做一小节，熟悉发音、拼写和最常见的句型。它把练习切得很短，适合每天在地铁或等外卖时完成；提醒和连续学习会推动你回来，但也不要把连续天数当成真正的水平证明。免费层能完成基础练习，具体课程、广告和次数限制会随语言与地区变化。

**2. BBC Bitesize**  
网址：https://www.bbc.co.uk/bitesize

当你不想只做选择题，可以进 BBC Bitesize 按主题找解释和练习。打开后先选学科或年龄段，再挑一页能读完的内容；它更像结构化的学习材料，不只是背词。对于刚入门的人，先把一篇短解释读完，再回到 Duolingo 练习，通常比同时打开十个课程更容易坚持。

![BBC Bitesize 页面](资源伸手党·成稿·05·新语言入门·20261117-1530_03_BBCBitesize.png)

**3. Open Culture**  
网址：https://www.openculture.com/freeonlinecourses

Open Culture 更像一张免费课程和材料索引。搜索语言或相关主题时，先看课程指向的原始平台、是否需要注册和当前是否仍可打开，再决定收藏哪一个。它和 BBC Bitesize 的区别是不会替你把课程全部装在一个学习界面里，适合已经知道自己想学“听力”“语法”还是“文学”的人。

![Open Culture 页面](资源伸手党·成稿·05·新语言入门·20261117-1530_04_OpenCulture.png)

**4. Project Gutenberg**  
网址：https://www.gutenberg.org/

等基础词汇多一点，可以把 Project Gutenberg 的公版书当作低压力阅读材料：先按语言或书名搜索，打开文本页，只读一小段，不必一上来啃长篇。今天主页可能遇到维护状态，恢复后再用更稳妥；如果你现在就要有声材料，可以先看下一项。不同国家的公版范围不完全一样，下载和再使用前要按所在地规则判断。

![Project Gutenberg 页面](资源伸手党·成稿·05·新语言入门·20261117-1530_05_ProjectGutenberg.png)

**5. LibriVox**  
网址：https://librivox.org/

LibriVox 把公版书做成有声读物。打开后先按语言或书名找一章，播放时不要追求每个词都听懂，只记下反复出现的短语，再回头查文本。它和 Gutenberg 的差别是让耳朵先适应节奏，适合散步、收拾房间时听。录音来自志愿者，音质和口音会有差异，正好可以当作不同听感练习。

最轻的开始方式是今天只做一节短练习，再听 LibriVox 的一章开头。等你愿意回来第二次，学习计划才算真正开始。
