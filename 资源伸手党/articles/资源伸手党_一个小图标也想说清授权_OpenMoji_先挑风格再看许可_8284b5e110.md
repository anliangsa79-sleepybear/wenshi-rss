# 一个小图标也想说清授权：OpenMoji 先挑风格再看许可

做演示、做课程资料或给个人项目配图时，最常见的麻烦不是找不到图标，而是找到之后不知道能不能改、能不能商用、需不需要署名。OpenMoji 把一套统一风格的表情图标放在公开网站上，适合先挑图，再把授权条件一起看清楚。

打开网站后，可以用搜索框输入英文或主题词，进入具体图标的详情页。先看大图是否适合你的尺寸和语境，再在下载区域选择 SVG 或 PNG。SVG 适合在设计软件里继续调整，PNG 适合直接放进文档或网页；如果只是要一个很小的提示符号，先下载两种格式各试一次，能避免后面因为像素或透明背景返工。

真正应该停下来看的，是页面上的许可证和署名要求。OpenMoji 使用 CC BY-SA 4.0，通常意味着使用时要保留适当署名；如果你改编后再发布，还要留意相同方式共享等条件。把图标放进商业海报、课程、应用或文章时，最好在项目的版权页、说明文档或图片旁边留下来源，不要因为图标很小就省掉这一步。

实际下载时，可以把图标名称、下载日期和许可证链接一并记在素材表里。以后重新导出、替换颜色或交给同事使用时，不需要再猜它从哪里来。若只是在内部草稿里试排，也不要把临时文件混进最终素材库，免得发布时漏掉署名。

它不负责替你判断某个图标和品牌、人物或产品的使用风险。下载后可以改颜色、换大小，但不要抹掉授权信息，也不要把网站上的图标重新包装成自己原创的一套素材。OpenMoji 的好处就在于风格统一、格式清楚、授权文本公开；真正省时间的用法，是把图标文件和许可说明一起归档。
