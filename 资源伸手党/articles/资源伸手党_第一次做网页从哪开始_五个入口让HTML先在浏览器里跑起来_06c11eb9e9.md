# 第一次做网页从哪开始？五个入口让HTML先在浏览器里跑起来

学网页开发，最容易卡在教程太多、却始终没看到自己的页面。可以先让一个标题在浏览器里出现，再逐步加入练习、项目路线和反馈：W3Schools解释标签，freeCodeCamp安排小任务，The Odin Project组织完整路径，CodePen提供即时预览，Exercism补逻辑训练。

## 🌐 先让浏览器显示一行文字

在 [W3Schools HTML](https://www.w3schools.com/html/) 找一个最小示例，只改标题文字或段落，再运行页面看结果。它适合快速查一个标签，像随手参考书；当你想要连续练习，可以进入 [freeCodeCamp](https://www.freecodecamp.org/learn/) 选入门模块，按题目改代码并看测试反馈。两者的区别是一个便于查，一个更像连续课程。

## 🧭 从练习走到自己的小项目

如果你需要知道下一步学什么，先浏览 [The Odin Project](https://www.theodinproject.com/paths) 的学习路径和项目要求，选当前能完成的一小段，不必一次承诺全栈课程。想马上看代码如何改变页面，到 [CodePen](https://codepen.io/pen/) 分别写一点 HTML、CSS，再观察预览；它像试验台，适合按钮、卡片和小动画，不替代基础学习。

![The Odin Project 学习路线](images/资源伸手党·成稿·05·第一次做网页·20261024-1030_03_Odin.png)

![CodePen 新建 Pen 页面](images/资源伸手党·成稿·05·第一次做网页·20261024-1030_04_CodePen.png)

最后可在 [Exercism](https://exercism.org/tracks) 选一门语言做练习，重点放在逻辑、函数和命名，而不是视觉效果。每个轨道的运行方式可能不同，先读说明再开始。

![Exercism 语言练习路线](images/资源伸手党·成稿·05·第一次做网页·20261024-1030_05_Exercism.png)

今天的目标可以很小：改一行文字，给它加颜色，再把页面截图或代码保存下来。公开作品前检查代码和素材许可；账号、课程进度和练习要求按各站当前页面为准。

保存每次尝试时保留一个能说明变化的版本，例如“标题文字”“背景颜色”“按钮点击后出现提示”，而不是只截图最终页面。遇到页面不如预期，先检查标签是否闭合、CSS选择器是否对应，再看浏览器控制台的提示。课程与在线编辑器的账号、保存和公开分享规则可能不同；初学阶段先用不含隐私信息的练习内容，发布前检查代码、图片和字体的授权。
