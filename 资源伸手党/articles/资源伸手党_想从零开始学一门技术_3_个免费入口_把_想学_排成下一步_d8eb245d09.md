# 想从零开始学一门技术：3 个免费入口，把“想学”排成下一步

“我想学编程”听起来像一个目标，真正开始时却不知道先学哪一门、看哪套课、做到什么算入门。下面三个入口刚好对应三种需要：中文课程帮助你排计划，系统课程带你做完整任务，官方文档则负责在遇到细节时给出准确答案。

中文学习可以先看 [中国大学 MOOC](https://www.icourse163.org/)。打开首页后搜索“Python”“数据结构”或你想学的主题，再看课程介绍、开课时间和章节安排。它更适合需要中文讲解、课程顺序和作业节奏的人，第一次使用不要同时报名十门课，先挑一门能在两周内完成前几章的。它和 CS50 的区别是中文课程选择很多、难度跨度大，适合先找到能坚持的入口，但课程质量和互动方式要逐门判断。

![中国大学 MOOC 课程入口](资源伸手党·成稿·04·从零学一门技术·20261028-1030.png)

如果你想知道计算机到底怎样工作，可以进入 [CS50](https://cs50.harvard.edu/x/)。从课程主页先看 week 目录，再选择讲座、短片和 problem set，按周完成，而不是只收藏视频。它的优势是把程序、算法、内存和项目放进一条完整路径里，适合愿意花时间做题的人；内容以英文为主，任务也比普通入门课更需要动手。它不是“看完就会”的速成课，最好给自己留出固定的每周时段。

![CS50 课程主页与周次入口](资源伸手党·成稿·04·从零学一门技术·20261028-1030_02_CS50.png)

当你已经写出第一段 Python，遇到语法和标准库问题时，直接查 [Python 官方教程](https://docs.python.org/3/tutorial/)。从 Tutorial 开始，按章节读示例、在本地运行，再用 Library Reference 查具体模块。它的优点是准确、更新由官方维护，不会为了“讲得轻松”而省掉重要细节；缺点是它不是为完全没有编程经验的人设计的，需要你自己安排顺序。

![Python 官方教程入口](资源伸手党·成稿·04·从零学一门技术·20261028-1030_03_Python.png)

比较稳的开始方式是：用中国大学 MOOC 确认方向，用 CS50 训练解决问题的耐心，再把 Python 文档当作随手可查的工具箱。课程、视频、练习和文档都可能有各自的账号、地区和授权限制，免费访问不等于可以随意下载、改名或重新售卖。
