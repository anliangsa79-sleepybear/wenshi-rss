# 想学一门新语言，先把免费听读材料排好：5 个入口从短到长

学语言最容易卡在“收藏了很多，今天不知道打开什么”。与其再找一个万能课程，不如把材料按难度排好：先读短文本，再听慢速内容，最后进入完整的公版书和有声书。下面这 5 个网站不负责替你制定目标，但能把第一步变得很具体。

**1. Project Gutenberg**（https://www.gutenberg.org/）

先用 Project Gutenberg 找一篇短的公版文本。打开后按语言、主题或书名搜索，第一步不要立刻下载厚书，先打开 HTML 在线阅读，看自己能否读完一页。它的优势是书多、格式直接，适合建立词汇和阅读耐力；与后面的 Standard Ebooks 相比，排版没有那么统一，选书时要自己判断难度。公版状态因地区而异，转载或商用前要再看具体说明。

![Project Gutenberg 电子书页面](资源伸手党·成稿·04·免费听读材料排好·20261024-1030.png)

**2. Standard Ebooks**（https://standardebooks.org/）

想把阅读体验弄得舒服一点，就换到 Standard Ebooks。它专门整理公版书，排版、目录和电子书格式都更讲究。打开后先按语言或主题挑一本，读目录和开头几页，不要被“经典”两个字吓住。它适合已经能连续读一段文字、在意排版和长期阅读的人。它提供的是制作得更好的公版书，不代表所有地区都用同一套版权规则。

![Standard Ebooks 书库页面](资源伸手党·成稿·04·免费听读材料排好·20261024-1030_02_StandardEbooks.png)

**3. BBC Learning English**（https://www.bbc.co.uk/learningenglish）

需要短听力时，BBC Learning English 比整本书更容易开始。打开后先按栏目找一个短课，听一遍不看文字，再回头看词汇或脚本。它和前两个站的区别是有课程节奏和音频，适合每天只挤出十分钟的人；内容和页面会更新，具体栏目名称以当前页面为准。

![BBC Learning English 页面](资源伸手党·成稿·04·免费听读材料排好·20261024-1030_03_BBCLearning.png)

**4. ELLLO**（https://elllo.org/）

如果你已经不想只听教材腔，可以试 ELLLO。页面按主题、说话者和难度提供大量听力材料，第一步是挑一段不超过几分钟的音频，先听大意，再看文字或练习。它和 BBC 的不同在于说话者和口音更杂，适合从“能听懂课文”过渡到“能听懂真实对话”的阶段。

![ELLLO 听力材料页面](资源伸手党·成稿·04·免费听读材料排好·20261024-1030_04_ELLLO.png)

**5. LibriVox**（https://librivox.org/）

最后用 LibriVox 把短练习接到长时间听读。它收录志愿者朗读的公版有声书，打开后先按语言和书名找一章，不必从第一章开始硬撑。它适合已经能抓住大意、想训练持续注意力的人；朗读者、音质和语速各不相同，正好可以当成真实听力的过渡。音频使用仍要看具体作品和地区的版权状态。

![LibriVox 有声书页面](资源伸手党·成稿·04·免费听读材料排好·20261024-1030_05_LibriVox.png)

今天只做一件事：选 BBC 或 ELLLO 的一段短音频，听完再读一页 Gutenberg。材料不是越多越好，能让你明天知道从哪里继续，才算真正排好了。
