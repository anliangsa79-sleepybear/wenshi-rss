# OpenStreetMap：把“地图上没有这条路”，变成一次真实的地图观察

![OpenStreetMap：把“地图上没有这条路”，变成一次真实的地图观察](资源伸手党·小功能·03·OpenStreetMap地图编辑·20261016-1030.png)

住在一个熟悉的小区里，最容易发现地图没有写清楚的细节：新开的公共厕所、刚改名的路、可以推婴儿车通过的小门。OpenStreetMap 不只是查路线，也允许用户在遵守规则的前提下补充开放地图数据。第一次使用，不必急着编辑，先学会观察地图和资料来源。

**先做什么**

打开 https://www.openstreetmap.org/，搜索自己熟悉的街区，放大后对照现实：道路、河流、公交站和公共设施是否已经标出。点开一个对象，看看它的名称、类型和最后修改信息。地图开放编辑，但不是“想怎么画就怎么画”。

**第一次编辑怎么做**

选择一个自己确实去过、能够确认位置的简单对象，阅读编辑器提示后再提交。不要凭猜测添加商店营业时间，不要把私人住址、门牌或敏感地点写进去，也不要复制其他地图的受版权保护数据。完成后回到地图看变化是否合理，必要时及时修正。

它适合地图爱好者、城市观察者、做路线研究的人，也适合让孩子理解“地图不是天上掉下来的”。数据开放并不意味着每个标注都绝对准确，编辑前后都要尊重社区规范。今晚先找一条自己每天走的路，看看它在地图上是否和记忆一样。

如果只是想练习，不必提交真实编辑：可以先在纸上画出街区，再对照地图看看自己漏掉了什么。真正提交时，尽量使用清楚、可复核的事实，给变化留出被其他贡献者检查的机会。地图上的一个小图标，背后其实是一次对公共空间的认真描述，这也是它比普通路线查询更有意思的地方。
