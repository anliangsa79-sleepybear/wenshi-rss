# 输了一盘棋却不知道输在哪里？Lichess 的分析棋盘会把那一步重新亮出来

![Lichess棋局复盘](资源伸手党·小功能·03·Lichess棋局复盘·20261017-1030.png)

下完一盘棋，最容易得出的结论是“我今天状态不好”。但真正有用的问题通常只有一个：哪一步开始，局面从还能下变成了很难下？Lichess 不只是在线对弈网站，它的分析棋盘、练习和研究功能，适合把一盘已经结束的棋拆开看。

## 先别急着看评价，自己走一遍

打开 https://lichess.org/ ，从 Tools 进入 Analysis board，或者打开自己的对局记录。先把引擎评价关掉，沿着棋谱重新走一遍，每到你觉得“这里应该没问题”的地方就停一下，写下自己当时的计划。这个步骤很重要：如果一开始就看红色数字，你只会记住哪一步变差，不一定知道自己为什么会走它。

## 再用引擎找一个关键分叉

打开 Stockfish 分析后，不用把整盘每个数字都抄下来，只找第一个明显变化的分叉。回到那一步，尝试两三个候选着法，看看对手最自然的回应是什么。你会发现很多失误不是“没看见将军”，而是忘了一个被攻击的子、低估了对手的强制手段，或者自己的计划没有配合局面。分析棋盘能给提示，但最后仍要用人话写出“我漏算了什么”。

说点实在的：Lichess 是免费、开源、无广告的在线国际象棋平台，部分分析需要等待服务器资源；注册后更方便保存对局，游客也能使用不少工具。引擎建议不是裁判，网络中断、设备性能和分析深度都会影响结果。公开分享棋局时，也要注意对手昵称和隐私。

下一盘棋结束后，只挑一个转折点复盘，并写下一个下次要检查的动作。比起把整盘棋重新看十遍，抓住那一个“当时为什么没想到”的瞬间，更容易真的变强。
