# 想找已经消失的网页，Wayback Machine 先把旧页面翻回来

电脑里还留着一条旧链接，点开却只剩页面不存在。这时候别急着把网址丢进普通搜索框，先打开 Wayback Machine。它把过去抓取到的网页按时间存下来，让你有机会回到某个旧版本。

## 🕰️ 先输入旧网址，再看它有没有被保存

打开 https://web.archive.org/，把完整网址粘进搜索框。不要只输入网站首页，文章页、产品页和个人博客要尽量保留原来的路径；同一个域名下，首页可能保存很多次，具体文章却一次也没有。提交后，如果时间轴和日历出现可选日期，说明至少有过抓取记录。

## 📅 把时间点拖回那一天

选年份，再点日历上有颜色标记的日期，最后从具体时间点进入页面。第一次打开可能遇到图片缺失、脚本失效或链接仍指向今天的地址，这不一定是存档坏了，而是当时只抓到了 HTML。可以换同一天的另一个时间点，也可以退回上一年试试。它最有用的地方不是“什么都能找回来”，而是帮你确认这条内容曾在什么时候、以什么样子公开出现过。旧网页的评论区、登录后内容和视频经常保存不全；如果要引用，最好把存档日期和原网址一起记下。

下次遇到失效链接，先试试 web.archive.org，别让一条 404 直接替历史做决定。要找的是旧页面而不是一个模糊印象时，尽量补上原网址、页面标题和大概日期；如果页面涉及交易、公告或规则，最好把存档时间和页面内容一起保存，因为存档本身也可能缺图、缺脚本，不能自动等同于完整原件。遇到多个日期时，先看最接近事件发生日的一次，再和更早、更晚的版本对照，往往能看出页面是改名、迁移，还是彻底下线。还可以把网页标题、页面截图和存档链接放在同一个文件夹，方便之后给别人解释你究竟找回了哪一版。若只是寻找旧文章，存档已经足够；若要证明法律或交易事实，还要回到机构原件。存档适合找线索和核对公开状态，不能替代合同、发票或官方原件。
