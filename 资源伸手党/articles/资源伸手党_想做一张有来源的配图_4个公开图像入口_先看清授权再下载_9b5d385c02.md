# 想做一张有来源的配图：4个公开图像入口，先看清授权再下载

![开放图像素材](资源伸手党·成稿·04·开放图像素材·20261021-1030.png)

做一张 PPT 或公众号配图，最容易犯的错不是审美不好，而是从搜索结果里随手保存一张图，发布时才发现不知道作者是谁、能不能改、能不能商用。下面四个入口更适合建立一个小型素材流程：先找对象，再看馆藏或作者信息，最后核对授权，不把“能看到”误当成“可以随便用”。

**1. 芝加哥艺术学院 API：先从一件作品开始**  
https://api.artic.edu/api/v1/artworks/search?q=monet&limit=1

这个公开接口适合搜索作品、作者和图像资料。不会写代码也没关系，直接打开官网的作品页，按标题或艺术家搜索即可；会写代码的人则可以利用 API 做一个自己的小画册。每张图都应回到作品记录确认版权状态，尤其是作品图像和博物馆页面文字，适用规则并不完全相同。

**2. unDraw：需要一张干净的概念插画时**  
https://undraw.co/illustrations

在插画库里按主题找图，打开单张作品后可以调整主色，再下载 SVG 或 PNG。它的优势是风格统一、适合网页和演示文稿，且许可说明相对清楚；它不适合拿来伪装成真实新闻照片，也不适合把整套插画重新包装成自己的素材库。

**3. Iconfont：给标题和流程补一个准确的小图标**  
https://www.iconfont.cn/

搜索时先用具体名词，例如“地图”“书”“耳机”，再看图标作者和授权说明。下载前要确认是 SVG 还是 PNG，并留意项目许可和署名要求。它和图库的区别是解决“小而准”的视觉问题：一个按钮、一个步骤、一个提示，不必用一张大照片把信息淹没。

**4. Flaticon：图标很多，但免费档要记得署名**  
https://www.flaticon.com/

输入关键词后先用风格和格式筛选，进入图标页再查看免费使用条件。它的优点是数量大、组合方便，缺点是免费资源常常附带署名要求，下载时也可能提示注册或升级。适合做草图和内部演示；对外发布前要把许可要求落实到页面或说明里。

一个稳妥的习惯是：每下载一张图，就同时保存来源链接、作者和许可截图或文字记录。这样将来要改图、补署名、换成另一种授权时，不必重新猜。开放素材省的是寻找时间，不是核对责任。
