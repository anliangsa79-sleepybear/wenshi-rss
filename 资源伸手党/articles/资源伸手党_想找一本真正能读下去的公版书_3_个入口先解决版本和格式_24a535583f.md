# 想找一本真正能读下去的公版书：3 个入口先解决版本和格式

想读一本经典作品时，最先遇到的常常不是“有没有”，而是版本太多：网页看着累，下载格式不合适，或者搜到的文件没有校对。下面三个入口可以按“先找到—读得舒服—再往档案里挖”的顺序用。

**1. Project Gutenberg**  
https://www.gutenberg.org/

先在 Project Gutenberg 搜书名或作者名，点进书籍页后看 HTML、EPUB、纯文本等格式。它适合快速找到英文和多语种公版书，网页阅读不用安装软件，下载也很直接。第一次使用时先确认作者和作品名，再看页面的发布说明；同名作品可能有不同译本或不同整理版本。它是这组入口里最适合“今晚就开始读”的一站，但公版范围按法域和作品而异，跨地区使用时仍要看说明。

![Project Gutenberg 公版电子书入口](资源伸手党·成稿·03·公版书先读起来·20261030-1030.png)

**2. Standard Ebooks**  
https://standardebooks.org/

如果你在意排版，Standard Ebooks 值得放在第二步。它把许多公版书重新整理成适合电子阅读器的版本，打开书籍页可以先看封面、简介和支持的格式，再下载 EPUB 或其他文件。和 Gutenberg 相比，它的书目少一些，但字体、目录、脚注和段落处理更统一，适合已经确定要读哪一本、希望读得舒服的人。

![Standard Ebooks 精排公版书页面](资源伸手党·成稿·03·公版书先读起来·20261030-1030_02_StandardEbooks.png)

**3. Internet Archive**  
https://archive.org/

当你想找旧版扫描、绝版书或相关影像，再去 Internet Archive。搜索后先看条目页的媒体类型、借阅或下载按钮和权利说明。有些资料可以直接阅读，有些需要借阅，有些只开放特定格式；它和前两个入口的不同，是档案跨度更大，但页面状态也更复杂，不适合把每个结果都当成可随时下载的公版文件。

![Internet Archive 数字图书馆入口](资源伸手党·成稿·03·公版书先读起来·20261030-1030_03_InternetArchive.png)

我会先用 Gutenberg 找到书，再用 Standard Ebooks 换成更舒服的版本，最后才把 Internet Archive 当作版本和史料线索。今天挑一本真正想读的书，先下载一个能在手机上打开的格式，读十页再决定要不要继续挖。

链接：Project Gutenberg、Standard Ebooks、Internet Archive。
