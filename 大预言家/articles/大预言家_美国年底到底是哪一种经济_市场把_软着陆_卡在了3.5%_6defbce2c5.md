# 美国年底到底是哪一种经济？市场把“软着陆”卡在了3.5%

美国经济预测市场今天摆出四个格子：过热、软着陆、滞胀和低迷。它没有让交易者直接回答“美国经济好不好”，而是规定两条线：失业率5%，通胀3.5%。到2026年年底，数据落在哪一边，就把经济送进哪个格子。

目前市场最看好的答案是“过热”，概率约六成半；软着陆排在后面。这个结果有一点反直觉。普通人听到“过热”，往往想到经济太强、股市太兴奋，似乎是好消息。可在这套规则里，过热的定义是失业率低于5%，同时通胀达到或超过3.5%。工作岗位不少，价格压力也没有真正下来。经济不是病得最重，却可能热得让政策制定者坐不住。

软着陆反而更讲究分寸。它要求失业率低于5%，但通胀低于3.5%。就业不能太差，物价也不能太高。只要失业率从4.9%升到5.0%，或者通胀从3.49%跳到3.5%，经济就会被送去别的格子。新闻里的“差不多”在这里没有用，边界就是边界。

这类市场最大的魅力，是把宏观经济从一团雾拆成一个简单矩阵。它最大的风险，也在于这种简单。美国经济当然不只有失业率和CPI，生产率、工资、消费、企业利润、住房和金融条件都很重要。可是预测市场需要一个可以结算的答案，于是复杂现实被压缩成两个数字，再由两个门槛切出四种命运。

“过热”之所以领先，可能是交易者认为美国就业仍然有韧性，而通胀会比政策目标顽固。这样的判断并不等于大家觉得经济正在失控。它更像是说，降温还没有降到足以让央行完全放心的位置。一个人有体温，但还没发烧到必须急诊；经济有动力，但价格压力仍在门口敲门。

另一个值得注意的地方，是市场的时间感。今天的概率并不是对年底美国的永久评价，它会随着就业报告、通胀报告和政策声明变化。每一个月的数字，都会重新问一遍：失业率有没有接近那条线，价格有没有继续黏住。越靠近年底，市场越可能从“方向判断”变成“边界竞猜”。

结算还设置了一个现实中的补丁。如果12月数据没有在规定时间内公布，就用此前可获得的最新月份。这听起来像技术细节，却揭示了预测市场和现实世界之间的差异。现实不会因为市场截止就准时交卷，交易规则却必须提前决定，迟到的数据到底算不算数。

如果最终落入“过热”，最有趣的问题不是经济是不是太好了，而是为什么好消息也会带来压力。就业强劲本应让人高兴，可当通胀仍高，强劲就会变成央行不敢松手的理由。如果落入软着陆，大家又会迅速把它写成经济管理的胜利，仿佛一路上的争论从未发生。

美国年底究竟属于哪一格，表面上是一个分类题，背后却是在问：我们愿不愿意接受一个经济同时拥有好消息和坏消息？市场给出的答案还不稳定，而那条3.5%的线，已经先替所有人制造了悬念。

两条线还会制造一种统计上的错觉。失业率和CPI都有自己的调查方法、发布时间和修订可能，它们并不是在同一天用同一把尺子量出来的。一个月就业数据看起来很强，随后又可能被修订；一项物价数据落在边界附近，季节调整也会改变市场的语气。规则把结果切得很整齐，数据本身却带着现实世界的毛边。

这也是为什么“过热”不应直接翻译成“繁荣”，“软着陆”也不该直接翻译成“所有人都过得不错”。分类市场提供的是一个可讨论的坐标，不是一张家庭生活的合影。美国经济可以整体强劲，同时让租房者、低收入劳动者或某个行业的人感到压力。最后落在哪个格子，只能告诉我们宏观温度，不能替每个人回答冷不冷。

四格分类还有一个写作上的好处：它迫使我们把含糊的判断说清楚。有人说美国经济“很强”，到底是就业强，还是物价强？有人说经济“要降温”，到底是失业率上升，还是通胀回落？市场未必提供最完整的模型，却把争论中的两个关键词摆到了同一张桌上。
