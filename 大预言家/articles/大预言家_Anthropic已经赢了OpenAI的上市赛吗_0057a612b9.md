# Anthropic已经赢了OpenAI的上市赛吗？

如果只看预测市场，Anthropic已经快要赢了。

Polymarket把Anthropic先于OpenAI完成IPO的概率定在96%左右，市场成交量超过40万美元。这个数字看上去很接近答案，可两家公司都还没有把股票交到公众手里。赛跑还没结束，盘口已经开始替它们安排颁奖顺序。

这里最容易误读的，是“先IPO”四个字。Anthropic在6月向美国证券交易委员会秘密提交了S-1草案，这是一个重要动作，但还不能算上市。公司提交文件以后，监管部门要审查，承销商要准备发行，股票要确定价格，交易所要接受挂牌。等到股票真正开始在公开市场正常交易，才算跨过这张盘口的终点线。

Anthropic的公告写得很谨慎。公司说，秘密提交草案让它拥有选择上市的权利，是否公开发行还要看监管审查、市场条件和其他因素。没有发行股数，也没有发行价格。换句话说，文件已经在路上，但列车还没有进站。

Anthropic是一家做人工智能模型的公司，最出名的产品是Claude。它的定位和OpenAI不完全一样，Claude早期就把安全、企业使用和长文本处理放在很醒目的位置。OpenAI则拥有更大的消费产品入口，ChatGPT把模型直接变成了普通人每天会打开的应用。两家公司的模型都在抢同一片市场，但公司走向公众市场的理由并不相同。

上市意味着筹到更多钱，也意味着从此要面对季度业绩、投资者提问和公开披露。对于一家需要持续购买算力、建设数据中心、训练下一代模型的公司来说，资本市场很有吸引力。可资本市场也不耐烦。它会问收入增长能不能覆盖算力账单，会问模型优势能维持多久，会问公司为什么还在亏损。

IPO还会改变公司讲故事的方式。私募融资时，公司可以围绕未来几年讨论收入规模、客户增长和技术路线，投资者数量也相对有限。公开上市以后，财报会按季度出现，现金流、资本开支和客户集中度都要被更多人看见。AI公司尤其难解释的是一张很大的基础设施账单：训练模型需要算力，服务用户也需要算力，而模型越受欢迎，成本未必越低。

Anthropic的S-1草案因此不是一张“上市通行证”，更像一份提前递交的问卷。它告诉监管者和市场，公司愿意走这条路，但没有承诺哪一天出发。公开发行还要受到市场气氛影响。如果科技股整体下跌，或者投资者突然不愿意为高增长但高亏损的公司付高价，原本接近完成的上市计划也可能放慢。

预测市场把Anthropic放在前面，可能不是因为它已经证明自己更适合做一家上市公司，而是因为它在公开程序上走得更快。OpenAI如果继续把重点放在私募融资、模型安全和基础设施上，哪怕估值继续上升，也不算赢得这场比赛。

这就让“先上市”变成了一个很有意思的比较。公司可以在私人市场里变得更值钱，却仍然没有完成IPO。某家公司可以先递交文件，却因为监管审查或市场转坏而停在门口。对于普通读者来说，看到一份S-1，往往会下意识地说“它要上市了”；对于结算规则来说，真正的答案只有一个：股票开始公开交易了吗？

OpenAI的情况更像另一条路。它可以继续筹集大额私募资金，把公司的价值留在公开市场之外。这样做的好处是少一些短期业绩压力，坏处是每一次融资都可能被拿来和未来的上市价格比较。Anthropic则把自己推到了更靠近交易所的位置，意味着它需要更早回答那些关于收入、亏损和算力投入的问题。

96%并不等于Anthropic已经完成了IPO。它只说明，在10月10日这个时间点，交易者认为Anthropic先跨过终点线的可能性远高于OpenAI。市场也给出了剩下的4%，那里面装着监管审查、市场条件变化、文件延迟，以及OpenAI突然改变计划的可能。

这场比赛的笑点在于，观众已经买好了票，运动员却还在更衣室里讨论要不要上场。Anthropic的S-1让它离跑道更近，OpenAI的融资和安全计划让它仍然站在另一条路上。谁先上市，最后不是由谁更会讲AI故事决定，而是由谁先完成那些不太浪漫的文件、审查、定价和挂牌。

所以，Anthropic还没有赢。它只是已经让市场相信，自己更接近终点。
