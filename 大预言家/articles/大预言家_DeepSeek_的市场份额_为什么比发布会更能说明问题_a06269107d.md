## 一场没有聚光灯的 AI 竞争

人工智能行业最容易被看见的是发布会：新模型上线，产品负责人登台，榜单分数刷新，媒体迅速给出“领先”或“反超”的标题。

卡尔希（Kalshi）上的 DeepSeek 市场份额盘口，讲的是另一种故事。它不问 DeepSeek 是否发布了令人惊讶的模型，而是问：在 OpenRouter 的文本模型作者市场份额中，DeepSeek 这周能不能超过某个门槛。

公开页面的快照显示，超过 22.9%约87%，超过 23.4%约72%，相关市场成交额约22.9万美元。两个门槛只相差 0.5 个百分点，概率却明显拉开。这说明市场在交易的不是“DeepSeek 有没有存在感”，而是它能不能把领先优势再向上推一点。

## 市场份额不是“所有 AI 使用量”

这类数字非常容易被标题夸大。OpenRouter 的文本模型作者市场份额，首先是一个特定聚合平台上的指标；它可能反映某一类 API 调用、文本模型选择和开发者流量，却不能直接代表全世界所有用户的 AI 使用量。

如果一篇文章把 23.4%写成“DeepSeek 占全球 AI 市场近四分之一”，那就已经跨过了数据边界。正确的写法应该是：在指定口径、指定时间窗口和指定数据来源下，市场对 DeepSeek 份额门槛的定价如何。

这不是语气上的谨慎，而是决定文章是否可靠的事实边界。一个模型在开发者 API 中增长很快，不代表它在普通用户应用、企业采购或移动端助手中也有同样份额；同样，一个平台份额下降，也不意味着模型能力一定下降。

## 为什么 0.5 个百分点会造成概率断层

22.9%和23.4%看起来像两个几乎相同的数字。对一个拥有巨大请求量的聚合平台来说，它们可能却对应不同的市场状态。

第一，份额是一种相对指标。DeepSeek 的份额上升，既可能来自自身请求增加，也可能来自竞争对手短期流量下降。第二，市场按特定时间窗口结算，某次产品更新、价格调整、热点事件或平台推荐，都可能改变一周内的请求结构。第三，数据通常会被四舍五入，门槛附近的几十分之一也可能影响结果。

因此，87%和72%之间的差距，不一定是交易者对 DeepSeek 长期前景的不同判断，更可能是对“本周能否穿过更高门槛”的不同判断。

## 使用量比发布会更接近真实，但也更容易被误读

市场份额题目的吸引力，在于它试图绕开宣传语言。发布会可以告诉我们模型多强，份额数据则告诉我们开发者有没有真的选它。

但“真实使用”并不等于“真实能力排名”。开发者可能因为价格、延迟、地域可用性、接口稳定性或某个热门功能选择模型。一个模型的调用量很高，可能是因为它便宜、方便，或者被某个应用默认接入，而不是因为它在所有任务上都胜过其他模型。

这使得份额市场特别适合写成一篇“指标解释”文章。我们可以同时承认它的价值和局限：它比发布会更接近实际使用，但它测量的是选择行为，不是模型能力的总分。

## DeepSeek 的竞争进入了第二阶段

当一个模型不再只被讨论“能不能追上”，而是开始被放进 22.9%和23.4%这样的精细盘口，它就进入了竞争的第二阶段。

第一阶段是注意力竞争：谁的发布会更受关注，谁能在榜单上制造话题。第二阶段是分发竞争：模型是否进入开发者工具、应用平台和企业工作流，能否持续占据调用份额。

第二阶段没有那么戏剧化，却更能决定行业结构。它不一定每天登上热搜，但会在 API 账单、路由平台和开发者选择中累积。

预测市场把这种累积过程变成了一个短期门槛。读者看到的不是“DeepSeek 赢了”，而是市场正在试图测量一个更具体的问题：它的关注度是否已经变成了可持续的使用量。

## 一张赔率表无法回答“谁最强”，却能回答“谁被使用”

这篇文章最后不需要给 DeepSeek 下结论。更有价值的结论是，AI 竞争正在从模型发布转向模型分发，从一次性的能力展示转向持续的调用行为。

市场份额不会告诉我们一个模型是否解决了所有问题，却会提醒我们：真正的竞争不只发生在实验室，也发生在每一次开发者选择模型的瞬间。

当 22.9%与23.4%之间出现明显的概率差，市场其实在说：增长已经被看见，下一步是证明它不是一次短暂的浪潮。
