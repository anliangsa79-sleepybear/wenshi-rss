# 大雨压塌邻家新屋老妇的破屋却没倒

连下了多日的雨，邻家新盖的屋子都倒了，马氏住的破屋却还撑着。屋柱本来就斜，门也修不起，拿破草荐遮着。她坐在里面，靠洗衣缝纫过活，卖掉做饭的釜后，拾了一只破瓦盆来替代。外头的人传说鬼神在保佑她，进屋看，却看不见多出的一碗粥。

马氏是东光人，与纪昀妻家的亲族有关系。未满二十岁便丧夫，没有公婆可依，也没有兄弟、子女可以相伴。一个年轻女人守在家中，最先面对的不是将来怎样留下名字，而是眼前这一天怎样把饭煮熟，下一件活又能换回多少粮。

她初寡时，本还有几亩薄田。有人想逼她改嫁，便侵凌得连田也失去了。这里所谓守节，并不是从头到尾关起门自作选择：外头有人施压，又有人把维持生活的土地夺走，她的决定是同这些真实损失挤在一处的。

那时的寡妇常被要求以不再婚来维护名节，乡里的称许与压迫又可能落在同一个人身上。故事后来称她“节妇”，用的是当时社会的评价；读她的日常，却不能把饥寒也看成应当奉献的一部分。

马氏靠浣濯和针线维生。浣濯就是替人洗衣，缝纫则把工夫落在衣物针脚上。一双手既要在水里揉洗，又要执针补缀，挣的是一点点辛劳钱。这样的生计，只要病上几天、天寒几日，饭食便可能接不上。

她穷到卖釜买粮。釜是煮食的锅，卖去本该是最后才能动的家用物；换来粮，又须拿别的东西把粮煮成饭。拾来的破瓦盆于是留在屋中，一面勉强补那个空，一面让每一次做饭都想起锅已经不在。

可是乡里传说，她小时候就被鬼神认作贵人。十一二岁随母亲到外家，屋外本有狐狸作怪，夜里掷瓦石击窗。忽然有人在屋上厉声呵斥，说这里有贵人，你们不要找死。此后人们便记住了这句看不见说话者的保护。

“贵人”落在童年小女孩身上，很容易使人往将来想：也许会嫁进显门，也许晚景富足，或者家中有人飞黄腾达。可马氏过到八十余岁，仍以普通民妇而终。几十年的岁月并未把那句话兑现成旁人容易辨认的衣食。

纪昀由此想到孟子所说的“天爵”，即仁义等德行所带来的尊贵，与人间官位的“人爵”相对。若把贵解释到这里，确可与一生清贫并存；但坐在破屋里的马氏，并不会因为概念被解释清楚，就少一夜冷，多一顿饭。

与她同里的李又聃先生曾作长诗，逐项写她的生活。诗里有空转的饥肠、手上的皴裂，有扫来的落叶充柴，有破荐代门。那些细节不再只说“穷”字，而让人看见，屋里每一件缺少的东西，都要由她拿另一件更差的东西补上。

雨中破屋不倒，也记在诗注里。邻近新屋塌了，她家欹斜的支柱反而撑住，人们很容易把这认作当年那声护持的后续。可屋没倒只是让人还活在里面，并未改变屋中难耐的日子。神怪故事在这里离人很近，又像始终只肯替她挡住最后一层风雨。

一次有贼从屋上经过，她听见便问，贼却大笑，说自己还不至于来这种饿鬼家里偷东西。一个夜里能使穷人提心的来客，看清这一家无物可取，反而用取笑作答。她获得的安全，是从窃贼也觉得不值得进门而来。

另有同巷贫妇，后来改嫁富户，穿着好衣回来看她，夸自己享用，笑她痴。衣服能把两种日子摆得很明白：一个终于有了可给人看的体面，一个仍在旧屋缝别人的衣。至于马氏怎样回答，诗没有替她留下反唇相讥的话。

亲朋渐少，她又羞于频频求助。无人来往，既是贫穷的结果，也使贫穷更难被外头看见。她不是从来不需要别人，只是每多开口一回，都可能耗去一点仅有的自持；等到不肯开口，旁人又容易说她原能安于如此。

李又聃的诗写到鬼神呵护，紧接着却说，人竟不怜贫。这一转，比只赞她心坚更重。若天上尚知保住一间破屋，眼前同乡为何不能替她添一点实在生计？诗不只把马氏立在远处供人敬仰，也把同在一乡的人拉近来问。

后来，周箓马公读到诗，割出三百亩好田，为她立嗣，并替她请求旌表。立嗣是安排延续家系的继承人，旌表则把某种德行送进官方褒奖的程序。此前薄田被侵夺而无人救，后来终于有人调动资源，行动之所以晚到，读者仍不免停一停。

三百亩田改变了家系的安排，也使长诗不只是纸上称颂。但那些年里已经饿过的日子，冻裂过的手，不能倒过来重过一次。故事留下这笔田，也留下破瓦盆，两件东西分量不同，却都在讲一个人如何被看见。

马氏丈夫的名字、她母亲的姓氏，纪昀后来都已忘了。屋上那声“贵人”倒还传着，像比一个人的具体姓名活得更久。雨停以后，破屋里若还放着那只瓦盆，盆沿接住的最后几滴水，是否也曾被她当作今晚煮饭的一点余用。
