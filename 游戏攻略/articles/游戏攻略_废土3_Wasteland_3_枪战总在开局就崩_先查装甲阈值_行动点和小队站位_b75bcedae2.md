# 《废土3》（Wasteland 3）枪战总在开局就崩？先查装甲阈值、行动点和小队站位

《废土3》的枪战容易让人误判成单纯比伤害。敌人的装甲、武器穿透、行动点和掩体都在影响同一轮决策。先把小队分工和开战位置安排好，战斗就不会每次都变成救火。

## 开战前先看敌人装甲

我更愿意把这件事当成路线判断：武器面板高不代表能有效击穿装甲，先看弹药、穿透和目标类型再决定谁开第一枪。 把这一步做好，下一段路会突然安静不少。

别把这一步理解成固定流程，它真正解决的是如果某个角色只能刮痧，换目标或使用破甲手段往往比继续射击更省行动点。 剩下的才是装备、等级和手感的差别。

开战前先问谁能破甲、谁能打断、谁能救人，回合结束前再检查下一格掩体。小队不是五把枪的总和，而是每个人都知道自己什么时候该动。
